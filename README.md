# 🖥️ Python System Resource Monitor

A Python-based system monitoring application that tracks CPU, memory, disk usage, and running processes. The project also provides threshold detection, alerts, statistics, visualization, reporting, and continuous system monitoring.

---

## 🚀 Features

- System information detection
- CPU usage monitoring
- RAM usage monitoring
- Disk usage monitoring
- Running process monitoring
- CPU and memory process analysis
- Resource threshold detection
- System alerts
- Monitoring history
- Resource statistics
- Data visualization
- System health analysis
- Continuous monitoring
- Automated text reports
- Interactive final monitoring dashboard
